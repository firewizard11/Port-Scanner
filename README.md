# Port Scanner

**Project Link:** <https://github.com/firewizard11/Port-Scanner>

## Description

Port Scanner is a CLI port scanner.

## Features

- Supported Scan Types: TCP connect
- Supported port formats:
  - single port: e.g. 80 or 443
  - port range: e.g. 1-65535
  - csv list: e.g. 21,22,443
- Sequential or Concurrent Scanning

## Install Guide

### Cloning Repository

```bash
git clone https://github.com/firewizard11/Port-Scanner.git
cd Port-Scanner
python3 port_scan.py
```

### Get a Windows .exe

Requires: 7zip

1. Downlaod [Windows Standalone](https://github.com/firewizard11/Port-Scanner/releases/tag/Windows) from Releases
2. Unzip `port_scan.7z` using 7zip
3. From inside a terminal run `.\port_scan.exe`

## Requirements

- Python3
- Python Standard Library
